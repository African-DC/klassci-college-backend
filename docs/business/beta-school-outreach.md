# Beta school outreach — KLASSCI College

**Objectif** : Identifier et onboarder **1 école beta gratuite** en S4 (mi-mai 2026)
qui pousse 50 vrais élèves dans la plateforme pendant 2 mois en échange de feedback.

## Profil idéal du contact

- **Directeur(trice) ou fondateur(trice)** d'un collège/lycée privé à Abidjan
- École de **taille petite-moyenne** (100-300 élèves) — assez gros pour avoir le besoin, assez petit pour adopter vite
- **Ouvert à la digitalisation** (déjà sur WhatsApp Business, Facebook actif, etc.)
- **Dans ton réseau personnel** (ami, ami d'ami, voisin) — pas un cold outreach

## Pourquoi 1 école et pas plusieurs

- Solo dev → bande passante limitée pour le support beta
- 1 école qui pousse à fond > 5 écoles qui testent superficiellement
- Feedback structuré récolté en flux tendu (WhatsApp dédié)
- Bug fixing tight loop (S5)

## Contrepartie offrée

| Pour l'école beta | Pour KLASSCI |
|---|---|
| **2 mois gratuits** (S4-S6) | Feedback réel sur le flow d'inscription/paiement |
| **3 mois supplémentaires offerts** après le launch (S10) si elle reste | Vrais élèves, vrais parents, vraie année académique |
| **Onboarding personnalisé** : call 1h pour configurer + import CSV | Stress test infrastructure (50 élèves = 50 parents = ~200 connexions/jour) |
| **Logo + témoignage** sur klassci.com après lancement (si elle accepte) | Social proof pour convertir les prospects en S8-S9 |
| **Hotline WhatsApp** dédiée pour la durée beta | Validation du modèle de pricing |
